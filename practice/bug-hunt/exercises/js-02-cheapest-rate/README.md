# js-02 · Cheapest rate

**Difficulty:** ●○○ (1/3)

## What it should do
`cheapestRate(offers)` returns the lowest nightly rate (in dollars) from a list of room offers.
It is used for the "from $___ per night" text on each property card.

## Examples
| Nightly rates in the offers | Output |
|---|---|
| `450, 95, 1200, 300` | `95` |
| `780, 1450` | `780` |
| `620` | `620` |
