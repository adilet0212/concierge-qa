# Concierge QA

WebdriverIO + Appium test automation for a luxury hotel guest app: web, mobile web and native Android,
with a demo app that can switch on six realistic regressions to prove the suite catches them.

The app under test is **Aurelle Hotels & Resorts, a fictional demo** modelled on the flows a hotel
guest app has (booking, in-room dining, guest requests, concierge chat, several languages and time zones).

## Quick start

```bash
npm install
npm run app          # builds and starts the demo app on http://localhost:4300 (leave it running)
npm run test:smoke   # in a second terminal
```

Full documentation is being written; see `docs/` and `practice/bug-hunt/`.
